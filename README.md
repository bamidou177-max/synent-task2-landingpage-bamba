# LearnX – Responsive Landing Page

LearnX is a modern and responsive landing page for an online learning platform.

## 🎯 Project Overview

This project was developed as part of the Synent Technologies Web Development Internship.

The goal was to create a clean, professional and responsive landing page for an online learning platform.

## ✨ Features

- Responsive design for desktop and mobile devices
- Hero section with call-to-action
- Features section
- About LearnX section
- Call-to-action section
- Footer
- Hover effects and smooth visual interactions

## 🛠️ Technologies

- HTML5
- CSS3
- Responsive Design
- Git
- GitHub

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `learn.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code.
